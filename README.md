# Tridip Pramanick — Portfolio

A personal portfolio built with React and Vite. Its layout takes inspiration from [shubhamz.dev](https://www.shubhamz.dev/), while the profile, project, experience, skills, research, and education content describe Tridip's own work.

## Run locally

```bash
cd app/frontend
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Build

```bash
cd app/frontend
npm run build
```
